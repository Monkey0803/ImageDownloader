### 本轮发现并修复的问题

v3 在 GIF/WebP 手动暂停后进入后台再返回，按钮由“继续”变成“暂停”，不同采样中画面继续换帧，暂停状态丢失。证据 `gif-paused-background-0-text/3-cmd/4-wait`、`webp-paused-background-3-text/6-cmd/7-wait`。主任务确认页面隐藏时取消扫描连带清除了预览源，导致动画组件重建；v4 保留源并仅挂起预览。v4 在 GIF 与 WebP 均已复验保持蓝色 FRAME 3 和“继续”按钮；前后台截图中央图像区域逐像素相同。证据 `v4-gif-paused-1-text/5-wait`、`v4-webp-paused-4-text/8-wait`。点击“继续”后恢复播放。回前台后的顶部文字经原图裁切与像素检查完整，不存在已确认的持续文字消失缺陷。

曾仅根据 UI 树含底层网格误判双指退出，随后核对 `v3-static-pinch.jpeg` 明确仍是放大预览，已撤回该误判，不列为产品缺陷。


v4 进一步发现真实双指放大同时隐藏工具栏：从 `v4-static-6-tap`（工具栏可见）直接注入 PointerMatrix，无额外单击，`v4-pinch-after` 已放大且控件隐藏。主任务在 v5 增加捏合期间及松手后短时间的点击抑制。v5 固定包 SHA-256 `07dcc632a7092d6e58a893f0ad7d67c462946e89bd9864f9de019ce72be3085b`，后续 v6 复验已通过，见最终版本段。
