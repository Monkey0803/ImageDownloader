# OCR 离线备用引擎：研究归档，不接入

**产品决定（2026-10-26）：用户选择保留系统 OCR，接受当前模拟器无法识别；本方案不接入应用。** 当前已批准的图库增强设计使用 CoreVisionKit。模拟器 `127.0.0.1:5555` 的 `com.huawei.hmsapp.hiai` 已启用，但 BundleManager 没有注册 `textService/TextServiceAbility`；真实 OCR 调用在连接该 Ability 时失败。此文仅保留本地替代方案的研究证据，不是实现完成证明。

## 已完成的独立原型

- RapidOCRLite 源码固定在 `4b6ea0935158aef0af911500f18058f1c87e96b2`，取其中 CPU C++ 源码、公开头文件及 Apache-2.0 许可文件约 3.2 MiB；不需要 80 MiB 的 Vulkan/x86 第三方目录。DevEco OpenHarmony ARM64 工具链可以直接构建，关闭 Vulkan、Metal、示例和测试后得到 `librapidocrlite.so` 约 7.4 MiB。
- 配套 PP-OCRv6 tiny：检测模型 `f42c0fbd294d95eac1a550e131b277dac97462c8025fa4b6c3cec1b7894bd3d5`（1.83 MB）、识别模型 `e16e242de5937ad92609223f19bc2aff3727ee40b095f996907c24749bad251b`（4.49 MB）、字典 `c5cbe34ef40c29c4df07ed012bf96569cb69a2d2a01a07027e9f13cb832bd9cd`（27 KB）。RapidOCR 上游将 PP 模型及转换产物声明为 Apache-2.0；正式分发前核对每个模型的来源、版权和随包许可文本。
- 模拟器 ARM64 命令行实际读出双语短图 4/4、空白图 0、长图 6/6 预期短语；单图独立进程 48–97 ms，最大 RSS 27–49 MiB。原始输出、设备命令及精确清理见 `/tmp/image-library-enhancements-20261026/ppocrv6-tiny-runtime/report.md`。这些数值不等于应用内峰值或真机性能。
- 另附的 Indra/lite 权重采用带用途限制的 OpenRAIL 修改许可，**不能混用、打包或作为本方案交付模型**。Tesseract fast/best/standard 均至少误识别一项固定中文短语，也不作为该方案。

## 若选择接入，应按顺序完成

1. **固定可复现资源。** 仅引入 CPU 编译所需的 RapidOCRLite 源码与 Apache-2.0 文本，保留上游提交和源码归属；将上述两个 PP 模型、字典及各自许可/来源信息放入应用资源。构建时禁止静默联网拉取模型。先用新资源在宿主机重跑短图、空白图、三块长图，核对 SHA 与结果。
2. **建立异步原生桥接。** NAPI 提供初始化、RGBA 像素识别和释放；输入宽高/行宽/缓冲区长度需有上限与溢出检查，先复制为引擎要求的 RGB。识别在后台线程执行，返回文字、置信度及图片坐标；C++ 异常/状态转换为可展示错误，句柄生命周期与 ArkTS 现有单引擎队列一致。一次索引作业复用已加载模型；取消在分块之间生效，并阻止旧结果写入目录。
3. **保持现有系统路径。** 支持的设备仍先使用 CoreVisionKit；仅当服务初始化明确不可用时切换到本地引擎，并将本次会话的引擎选择缓存，避免每张图重复等待。单图工具和图库按需索引共用选择结果；失败、空白、取消分别保留现有语义。不能只用 `canIUse()` 推断 OCR 服务存在。
4. **按原验收契约验证。** 构建主/测试 HAP、运行既有宿主及原生测试；在模拟器真实操作建立索引、搜索短图四短语及长图顶/中/尾六短语、空白图、取消/重试、改名/重启、原文件变化失效，确认搜索打开正确图片及片段。记录最终 HAP 增量、应用内内存/耗时，不把 CLI 数据当应用数据。
5. **恢复。** 与操作前用户数据及文件清单逐项比较，只清理本轮 QA 记录、模型临时复制文件和测试图，不覆盖其他任务产生的并发变化；更新验收记录和计划的 OCR checkbox。

## 接入边界

当前原型在仓库之外，产品代码没有 NAPI 桥接或模型资源。两模型、字典及 ARM64 库原始合计约 13.8 MB；压缩后的 HAP 实际增量、首次模型复制空间、应用内内存、其他 ABI、更多真实图片准确率尚未测量。用户已明确选择不增加该引擎与安装包体积；原型和源码不应进入产品构建。系统 OCR 的真实识别与内容搜索应在具有相应服务的真机上验收。
