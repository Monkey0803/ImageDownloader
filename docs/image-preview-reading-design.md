# 图片浏览阅读体验（2026-10-26）

目标顺序：手势完善 → 长图导航 → 浏览位置记忆，同时补齐性能和前后台验证。

## 行为与验收约定

| 要求 | 实现行为 | 必须验证的场景 |
| --- | --- | --- |
| 惯性拖动 | 放大后松手按速度衰减，按内容边界收敛；新触摸立即停止惯性 | 慢拖、快速拖、触摸打断、后台中断，无错图或持续定时器 |
| 边缘回弹 | 超出边缘时阻尼位移最大64vp，松手回到有效范围 | 四边、图片小于某一轴视口、双指接管、取消手势 |
| 下滑关闭 | 未放大时垂直下拉，距离或速度满足门槛才关闭；轻拉回位 | 静图、动图、水平换图、放大长图不能误关闭、弹层不穿透 |
| 长图导航 | 顶部、底部、0–100%进度滑块，进入适合宽度阅读 | 0/50/100对应实际图像段，拖动更新进度，横屏仍可操作 |
| 按图记忆 | 保存模式、缩放、图像中心位置；用图片身份绑定而非数组序号 | A→B→A、跳页、关闭重开、筛选换序、下载原图升级、转屏 |
| 记忆边界 | 本地记录ID对应位置跨重启保留；网页位置仅进程内保存；图像尺寸改变使旧记录失效 | 本地图强停重启；网页URL不落盘；坏文件/部分写入不能覆盖旧数据 |
| 前后台 | Ability与页面可见性共同控制；后台取消在途预览，释放静图/动图帧并停止惯性 | 发现预览不退出，静图保位置，动图恢复当前帧，手动暂停状态不丢失 |
| 性能 | 底图最多300万像素，不随缩放重复整图升级；细节仅按可见区域与实际显示尺寸解码，最多800万像素 | 连续切图/长图导航/动图/多轮开关和前后台的内存、CPU与响应；不以单次PSS充当峰值 |

## 数据与资源

- `PreviewReadingState` 保存数值型阅读位置；100条LRU，不持有PixelMap、组件或登录凭据。
- `PreviewReadingStore` 将`local:`记录ID写入应用文件目录的`preview-reading.json`，使用临时文件、完整性核对和改名替换；手势结束后合并写入，后台/退出时刷新。
- 网页记忆以来源页和图片URL区分，仅留在内存，不将URL或Cookie写入阅读位置文件。双图对比的变换独立，不写主图位置。
- 位置尺寸以原图像素校验，中心为原图归一化位置，转屏时重新计算边界；“适合屏幕/宽度/原始像素”保留各自语义。
- 图片仍采用原有5张/32MiB会话文件缓存，阅读位置不是图片缓存，不改变下载或清理语义。
