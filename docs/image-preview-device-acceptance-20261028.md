## 补验：真实双指、导出副本、快速切图/前后台

- **真实双指**：用 `uinput -T -m` 同时注入两个触点（不是单指拖动代替），在本地照片上从
  (550,1400)/(750,1400) 拉开到 (300,1400)/(1000,1400)。操作前后整图区域像素差
  `bbox=(0,0,1316,1800)`、差值 530,227,047，画面明显放大。截图
  `.screenshots/preview-final-pinch-before-20261028.png` / `...-after-...png`。
- **导出副本字节**：用 800×600、4,392 B 的 `export-qa.png` 导出到系统 Download；
  系统副本独立拉回后 SHA-256 为 `4db27a62add9e42d948c0a05d239d7a176fa6f98ff924d059882e36c724213fe`，
  与应用内原件逐字节相同（`cmp` 通过），随后删除系统副本。
- **快速切图**：在适合屏幕状态连续左滑，1/10 → 2/10 → 3/10 → 4/10 → 5/10，标题随页码切换；
  放大状态下横滑会先平移图片，点“适合屏幕”后才翻页，这是当前手势优先级。
- **前后台**：在第 5/10 张按 Home，等待 3 秒后重新启动应用，仍停在同一张 5/10 及同一文件。
