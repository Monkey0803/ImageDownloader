# HDS 导航与全局沉浸接入结果

## 变更

- `Index` 以单个 `HdsNavigation` 和 `NavPathStack` 承载四个 `HdsTabs` 页签；批量处理页并入主栈。图库查看器和图片编辑器继续使用独立页面 Router。
- 四页标题与操作移入 HDS 标题栏；发现页地址输入仍是标题栏自定义内容。移除旧的局部导航及未再使用的自定义标题、页签组件。
- HDS 标题栏、悬浮页签分别配置材质；设置关闭、设备不支持或网页浏览底栏时降级为无材质。结果页隐藏底部页签，保留原有返回语义。
- `EntryAbility` 继续沿用全屏窗口，统一读取状态栏、导航指示条、手势区及挖孔避让区；安全区变化时刷新主界面布局。
- 未改 SDK、包名、签名、权限、设备清单与独立页面路由。

## 验证与限制

- 接入前后 `assembleHap` 成功；新增 ArkTS ERROR 为 0。`entry@ohosTest` 构建成功，模拟器 Hypium 197/197 通过，含新增 HDS 导航和窗口避让策略 4 个用例。测试结束已卸载 `entry_test` 并恢复生产应用。
- 在 `127.0.0.1:5555` 模拟器验收四页标题与悬浮页签、页签切换、批量页进入与返回、图库独立查看器进入与返回，以及浅色和深色设置页。发现网页页签保持不透明底栏；修复了切换到设置后残留图库标题操作的问题。主题已恢复为“跟随系统”。设备截图保存在忽略目录 `.screenshots/`。
- 键盘、旋转、窗口尺寸变化及独立编辑器的交互尚未完成设备视觉验收；真机材质表现也未验证。
