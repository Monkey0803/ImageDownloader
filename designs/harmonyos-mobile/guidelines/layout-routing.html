先定布局，再谈间距
规范里间距不是全局常量 —— 它取决于命中哪个布局与哪个标题栏变体。所以第一步永远是路由： 这页是 card / grid / list 里的哪一种？
布局画布命中特征内容起点
mobile-card360×780固定 titlebar → search 首项 → 多卡片类型垂直堆叠，section header 分区96px（normal 变体）
mobile-grid360×792titlebar → search → chipstab 分类栏 → 水平滚动宫格 + 多区域混合96px 或 124px
mobile-list360×792主体是入口型 list item，按语义分组成圆角卡片；设置页以控件型 item 为主也命中此布局96px 或 124px
标题栏变体决定内容起点（规范强制）
标题栏变体内容 padding-top原因
normal（仅标题）96px文字层底边 88 + 强制间距 8
secondary（标题 + 副标题）等于完整标题栏高度规范：search 不得压过 secondary 标题栏
本系统的处理：内容起点 = safe-top + --harmony-titlebar-layer-<variant> + --harmony-titlebar-gap， 由 SizeFrame 所在画布上的 data-titlebar 决定取哪一档，而不是把 96 写死。
三个 UI kit 就是这三种布局的还原
ui_kits/card · grid · list · settings —— 新页面从最接近的那套起手，几何自然正确。
