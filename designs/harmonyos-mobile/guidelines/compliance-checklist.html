B · 六个已经踩过的坑（本系统全部修过）
#陷阱症状 / 修法
1模板 url() 路径是相对参考库写的 搬迁到 components/<group>/ 后状态栏 PNG 全 404。导入器现在重写路径，且资产缺失直接构建失败。
2模板把模糊半径写成固定字面量 --titlebar-blur: 12px / --bt-blur: 80px 写死 → 材质等级对最显眼的两处完全无效。
3自定义属性在声明处结算，不在使用处 :root 里写 calc(80px * var(--scale)) 会冻结 :root 的 scale，后代的 data-material-level 传不进去。派生必须写在携带属性的元素上。
4CSS 注释不嵌套 自动注释器把 /* @kind */ 插进注释中间 → 注释提前闭合、后半句变非法 CSS，把紧随其后的 [data-material-level="exquisite"] 整块吃掉。
5编译器会剥掉 react 的 import import { useEffect } from "react" 编译通过、运行时抛 ReferenceError。hook 必须从全局 React 取。
6box-sizing 复位的作用域漏了真正的画布 复位只写了 .hm-frame，而真画布是 .hm-size → 胶囊 56+8 内边距 = 64px，进而吃掉容器 16px 顶余量。
7同一块空间被算两次 --tabbar-space: 84px 已含 28px 指示区，又叠了 --safe-bottom: 6px → 净空 34px 而非规范 28px。
9规范模板自身缺资源：标题栏状态图标只给几何、无 background-image 标题栏内置状态行渲染成四个空框。状态栏模板确有该图（--statusbar-*-icon），同款同尺寸 —— 已在 theme-bridge.css 接上，不另画。
8状态栏区高度各家不一致 规范文字 36、page token 36、我最初写 32 → 标题与内容各自偏移 4px。统一由 --harmony-page-padding-mobile-top 派生。
